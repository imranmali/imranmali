## 🚀 About Me

I design and build **high-throughput, cloud-native backend systems** that scale from prototype to production without losing sight of maintainability or correctness.

With **8+ years** of hands-on engineering — spanning **Java 21**, **Spring Boot 3**, **microservices**, and **multi-cloud infrastructure** — I focus on solving the problems that matter: distributed consistency, performance at scale, and systems that operators can actually reason about.

My work spans event-driven architectures, RESTful API design (contract-first), security engineering (OAuth2 / DPoP), and cloud-native deployments on both **AWS** and **GCP**. I care deeply about observability, resilience, and keeping complexity where it belongs.

> *"Software is a craft. Ship systems that last, not just code that works."*
